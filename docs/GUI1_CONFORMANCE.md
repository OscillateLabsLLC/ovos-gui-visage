# OVOS-GUI-1 conformance

Spec: `OpenVoiceOS/architecture`, branch `dev`, `gui-1.md` at commit `b6c1583`. Line numbers below are at that
commit. Plan: `docs/GUI1_PLAN.md` section 3. Where Visage already follows a drafted amendment (gui1-upstream
`SPEC_PROPOSALS.md`, branches `gui1/*`, not merged), the row names the amendment and the branch.

Status values:

- `none`: Visage does not do this yet.
- `partial`: Visage does some of it; the notes say what is missing.
- `done`: Visage does it and the named test proves it.

`test/conformance_test.dart` reads this file. It fails when a template in `lib/pages/template_names.dart` has no row,
when a status is not one of the three values, when a `done` row names no test, or when a named Visage test file does not
exist. An adapter row may name the adapter's own tests as `ovos-gui-plugin-visage/test/<file>::<test>`; those count as a
named test but live in the other repository, so the test does not look for them. Run it alone with `just conformance`.
