How it fits the code

  • The widget keeps the animation state and hands every painter the same FaceFrame; styles only draw.
  • A FaceLayout gives each style its slots: two eye circles and a mouth box, full or compact. The layout comes from the frame (bare screen, badge disc, or the Mark 1 plate), never from the style.
  • FaceTheme stays the type the widget consumes; a ComposedTheme(eyes, mouth, frame) implements it and visage and mark1 become presets.
  • Mouth size is a layout parameter, not a style: large scales the mouth slot by 1.4 (1.25 in the badge, where the disc bounds it), so every mouth has a big version and the stroke weight grows with it.
  • Config: "face": "mark1" for a preset, "face": {"eyes": "block", "mouth": "outline", "mouthSize": "large"} for a pair, VISAGE_FACE=block+outline from the shell.
  • Colour later: each style reads eye, eyeDim, mouth, accent and glow and nothing else.
